# Sleepy 개인정보 처리방침

**앱 이름:** Sleepy - All in One
**패키지명:** `com.supsuphansoup.sleepy`
**최종 수정일:** 2026년 10월 14일

---

## 요약

Sleepy는 알람·타이머·수면 데이터를 **기기 안에서만** 다룹니다.
개발자가 운영하는 계정·서버나 자체 사용 분석 기능은 없습니다.

무료 이용 시 **Google AdMob** 배너와 알람 저장 후 전면 광고가 표시될 수 있습니다.
광고 SDK는 광고·분석·부정행위 방지 목적으로 정보를 처리하며, 자세한 항목은 광고 항목에 설명합니다.
광고와 인앱 결제는 Google이 처리합니다. 정보가 기기를 벗어나는 것은 그 범위와,
사용자가 직접 '의견 보내기'를 사용할 때뿐입니다.

## 1. 기기에만 저장되는 정보

아래 정보는 기기 내부 저장소에 보관되며 어디에도 전송되지 않습니다.

| 항목 | 내용 |
|---|---|
| 알람 설정 | 시각, 이름, 반복 요일 및 날짜, 소리·진동 설정, 음량, 스마트 알람 사용 여부 |
| 타이머 설정 | 타이머 모드, 수면 자동화 동작, 요일별 예약 |
| 알람음 | 사용자가 추가한 오디오 파일의 사본 |
| 구매 여부 | '광고 제거' · '스마트 알람'을 구매했는지에 대한 참/거짓 값 |
| 스마트 예측 | 취침 시각 이력(최근 30개·30일), 파생값(수면 주기·잠들기까지 지연·유효 밤 수·평소 잠드는 시각), 예약 캐시 |

앱을 삭제하면 위 정보는 기기에서 함께 삭제됩니다.

## 2. 수면 데이터 (스마트 알람)

스마트 알람을 구매했고 헬스 커넥트 수면 권한을 허용한 경우, 앱이 열려 있을 때만 최근 30일 수면 기록을 읽습니다.
웨어러블이 기록한 수면 세션과 수면 단계로 예상 기상 시각을 예약합니다.
폰 움직임 센서는 사용하지 않습니다. 현재 수면 단계를 실시간으로 감지하지 않습니다.

| 출처 | 읽는 내용 |
|---|---|
| 헬스 커넥트 (`android.permission.health.READ_SLEEP`) | 수면 세션과 수면 단계(얕은 잠 · 깊은 잠 · REM · 깸) |

- HC 원본은 저장·전송하지 않습니다. 읽은 기록으로 파생값(수면 주기·잠들기까지 지연·유효 밤 수·평소 잠드는 시각)만 계산·저장합니다.
- 취침 알림은 기본 켜짐이며 설정에서 끌 수 있습니다. 평소 잠드는 시각과 취침 이력으로 잘게요 입력을 안내하며, 알림 설정·보낸 알람 회차는 폰 안에만 저장됩니다.
- 잘게요 버튼과 수면 타이머 시작의 취침 시각 이력(최근 30개·30일), 파생값과 예약 캐시는 폰 안에만 저장됩니다.
- 이 정보는 개발자를 포함한 **어떤 외부로도 전송하지 않습니다.**
- 헬스 커넥트 권한은 언제든지 헬스 커넥트 앱에서 철회할 수 있으며,
  철회하면 헬스 커넥트 데이터는 읽지 않습니다. 권한·유효 기록 3밤·취침 입력이 없으면 정시 알람은 유지됩니다.
- 스마트 알람을 구매하지 않았거나 환불로 구매 권리가 철회되면 수면 기록을 읽지 않습니다.

## 3. 광고

무료 이용 시 화면 하단에 **Google AdMob** 배너와 알람 저장 후 전면 광고가 표시될 수 있습니다.
전면 광고의 빈도 제한을 위한 최근 저장·노출 시각은 기기에만 저장하며 개발자에게 전송하지 않습니다.

- Google Mobile Ads SDK는 광고·분석·부정행위 방지 목적으로 아래 정보를 자동으로 수집·공유할 수 있습니다.
  - 앱 상호작용(앱 실행·탭·동영상 조회)
  - 진단 정보(앱·SDK 성능)
  - 기기·계정 식별자(광고 ID·앱 세트 ID 등)
  - IP 주소(대략적인 위치 추정에 사용)
- 이 정보는 **Google이 직접 수집·처리**하며 개발자는 열람하지 않습니다.
  개발자가 확인할 수 있는 것은 노출 수·수익 같은 집계 통계뿐입니다.
- 자세한 내용은 Google의 개인정보처리방침(<https://policies.google.com/privacy>)과
  Mobile Ads SDK 데이터 공개(<https://developers.google.com/admob/android/privacy/play-data-disclosure>)를 참고하세요.

**광고를 원하지 않으시면:**

- 앱 내 **설정 → 스토어 → 광고 제거**(1회성 구매)를 이용하시면 배너와 전면 광고가 사라지고,
  **'스마트 알람' 상품에도 광고 제거가 포함됩니다.**
  구매 권리가 확인된 광고 제거(remove_ads) 또는 스마트 알람(smart_alarm) 구매자에게는
  광고 SDK를 초기화하지 않고 광고를 요청하지 않습니다.
- 기기 차원에서는 안드로이드 **설정 → 개인정보 보호 → 광고**에서 광고 ID를 초기화하거나
  맞춤 광고를 끌 수 있습니다.

## 4. 인앱 결제

인앱 결제는 **Google Play**가 처리합니다.

- 카드 번호 등 **결제 수단 정보는 이 앱에 전달되지 않습니다.**
- 앱은 Google Play로부터 '해당 상품을 구매했는지 여부'만 확인해 기기에 저장합니다.
- 구매 기록은 Google 계정에 남으므로 기기를 바꾸거나 앱을 다시 설치해도 복원됩니다.
- 환불·결제 문의는 Google Play 고객센터를 이용해 주세요.

| 상품 ID | 내용 |
|---|---|
| `remove_ads` | 광고 제거 |
| `smart_alarm` | 스마트 알람 해금 + 광고 제거 |

## 5. 의견 보내기

설정 화면의 **'개발자에게 의견 보내기'** 로 문의를 보낼 때에 한해 아래 정보가 전송됩니다.

- 입력하신 **이메일 주소** (답변 회신용)
- 입력하신 **문의 내용**

전송은 폼 처리 서비스 **Formspree**(`formspree.io`)를 통해 개발자에게 전달됩니다.
이 정보는 문의에 대한 답변 목적으로만 사용하며, 판매하거나 제3자에게 제공하지 않습니다.
Formspree의 데이터 처리에 관해서는 해당 서비스의 개인정보 처리방침(<https://formspree.io/legal/privacy-policy/>)을 참고하세요.

## 6. 수집하지 않는 정보

- 이름, 생년월일, 전화번호 등 신원 정보
- 정밀 위치 정보 (GPS)
- 연락처, 사진, 파일 목록
- 마이크 및 카메라 입력
- 개발자는 별도 분석 SDK나 서버로 앱 사용 통계·행동 로그를 수집하지 않습니다. 광고 SDK의 자동 처리는 광고 항목에 설명합니다.
- HC 원본의 저장·전송 (2항 참조 — 로컬 파생값·취침 이력·예약 캐시만 보관합니다)

## 7. 권한 사용 목적

| 권한 | 사용 목적 |
|---|---|
| 알림 (`POST_NOTIFICATIONS`) | 알람 화면 표시, 타이머 진행 상태 알림 |
| 정확한 알람 (`USE_EXACT_ALARM`, `SCHEDULE_EXACT_ALARM`) | 설정한 시각에 맞춰 알람 예약 |
| 진동 (`VIBRATE`) | 알람·타이머 진동 |
| 절전 모드 해제 (`WAKE_LOCK`) | 화면이 꺼진 동안에도 알람·타이머 소리를 유지 |
| 전체 화면 알림 (`USE_FULL_SCREEN_INTENT`) | 잠금 화면 위에 알람 화면 표시 |
| 오디오 설정 (`MODIFY_AUDIO_SETTINGS`) | 알람 음량 조절 |
| 방해금지 접근 (`ACCESS_NOTIFICATION_POLICY`) | 수면 타이머 종료 시 무음/진동 모드 전환 |
| 부팅 완료 수신 (`RECEIVE_BOOT_COMPLETED`) | 재부팅 후 등록된 정시 알람과 캐시 기반 예상 예약 복원 |
| 포그라운드 서비스 (`FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SYSTEM_EXEMPTED`, `FOREGROUND_SERVICE_SPECIAL_USE`) | 알람 소리·진동 재생과 타이머를 백그라운드에서 유지 |
| 수면 데이터 읽기 (`android.permission.health.READ_SLEEP`, 선택) | 지난 수면 기록으로 개인화된 예상 기상 시각 계산 (2항 참조) |
| 다른 앱 위에 표시 (`SYSTEM_ALERT_WINDOW`, 선택) | 수면 타이머의 검은 화면과 알람·타이머 종료 화면 표시. 사용자가 직접 허용해야 하는 선택 기능입니다 |
| 인앱 결제 (`com.android.vending.BILLING`) | 광고 제거·스마트 알람 구매 |
| 광고 ID (`com.google.android.gms.permission.AD_ID`) | AdMob 광고 게재 (3항 참조). 광고 제거 구매 시 사용하지 않습니다 |
| 인터넷 (`INTERNET`) | 광고 표시, '의견 보내기' 전송 |
| 네트워크 상태 · 광고 서비스 (`ACCESS_NETWORK_STATE`, `ACCESS_ADSERVICES_AD_ID`, `ACCESS_ADSERVICES_ATTRIBUTION`, `ACCESS_ADSERVICES_TOPICS`) | Google Mobile Ads SDK가 자동으로 추가하는 권한입니다. 광고 요청과 안드로이드 개인정보 보호 샌드박스 연동에 쓰이며, 앱 코드가 직접 사용하지는 않습니다 |

모든 권한은 위 기능을 수행하는 데에만 사용됩니다.
표의 권한은 최종 병합된 `AndroidManifest.xml` 기준이며, 일부는 앱이 아니라 포함된 SDK가 선언합니다.

## 8. 아동의 개인정보

이 앱은 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

## 9. 데이터 보관 및 삭제

- 기기에 저장된 데이터: 앱 삭제 시 함께 삭제됩니다. 앱 설정에서 개별 알람·음원을 직접 삭제할 수도 있습니다.
- 취침 시각 이력은 최근 30개·30일만 보관하며, 파생값과 예약 캐시를 포함한 로컬 정보는 앱 삭제 시 삭제됩니다. 헬스 커넥트에 저장된 원본은 헬스 커넥트 앱에서 관리하세요.
- 광고 관련 데이터: Google이 보관하며, 광고 ID 초기화로 연결을 끊을 수 있습니다.
- 의견 보내기로 전송된 내용: 답변 처리 후 보관할 필요가 없어지면 삭제합니다. 삭제를 원하시면 아래 연락처로 요청해 주세요.

## 10. 처리방침 변경

내용이 변경되면 이 문서의 '최종 수정일'을 갱신하고, 앱 내 설정 → 개인정보 처리방침에도 동일하게 반영합니다.

## 11. 문의

개인정보 처리에 관한 문의는 앱 내 **설정 → 개발자에게 의견 보내기** 를 이용해 주세요.
